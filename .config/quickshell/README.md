# Quickshell Status Bar v2 (Hyprland / CachyOS)

## Layout

```
[ 󰣇 | VPN pill | あ い う え お … ]        [  HH:mm  ddd dd MMM  ]        [ ⚡ ▓▓▓▓░░ 82% ]
        LEFT                                   CENTER                       RIGHT
```

- **LEFT** — Arch icon, ProtonVPN pill, Hyprland workspaces (hiragana labels)
- **CENTER** — clock pill
- **RIGHT** — battery progress-bar pill (UPower, event-driven)

## Files

| File | Purpose |
|---|---|
| `shell.qml` | Entry point: loads `Bar`, `MediaPlayer`, `osd/OSD` |
| `Bar.qml` | Pill bar window (radius 20, `Colors.barBackground`) |
| `Clock.qml` | Centered clock (minute precision, no 1s polling) |
| `BatteryBar.qml` | Battery progress fill pill; red <20%; bolt when charging; shimmer sweep on plug-in (~4.5s, then stops) |
| `VPNPill.qml` | ProtonVPN state via `ip link show proton0`, 30s poll + click-to-refresh |
| `Workspaces.qml` | Hyprland workspaces, hiragana labels, event-driven via `Quickshell.Hyprland` |
| `Colors.qml` | Singleton palette (**matugen-regenerated** — see below) |
| `MediaPlayer.qml` | MPRIS popup; **fixed**: `updateTimer` now stops on hide (`onVisibleChanged` on the Scope) |
| `osd/OSD.qml` | Volume OSD (Pipewire, event-driven) |
| `scripts/vpn-status.sh` | Manual/parity status script (the pill checks inline via `Process`) |
| `qmldir` | Declares `Colors` as a QML singleton |

## Install / test

```sh
# 1. Copy to a scratch config so your current bar keeps running:
mkdir -p ~/.config/quickshell-v2
cp -r qs-bar-v2/* ~/.config/quickshell-v2/

# 2. Test:
qs -p ~/.config/quickshell-v2/shell.qml
# or: quickshell -p ~/.config/quickshell-v2

# 3. Swap in (backup first):
mv ~/.config/quickshell ~/.config/quickshell.bak
mv ~/.config/quickshell-v2 ~/.config/quickshell
qs kill; qs   # or restart via your hyprland exec-once
```

## Important: Colors.qml is generated by matugen

`Colors.qml` is regenerated from your matugen template on every wallpaper
change. **Do not hand-edit it.** To change the palette, edit the matugen
template (e.g. `~/.config/matugen/templates/quickshell-colors.qml`) and add the
template to your matugen config, then re-run `matugen image <wallpaper>`.
The property names used by the bar are: `barBackground`, `pillBackground`,
`background`, `foreground`, `accent`, `accentAlt`, `success`, `warning`,
`danger`, `vpn`, `vpnDisconnected`, `text`, `textDim`, `workspaceActive`,
`workspaceOccupied`, `workspaceEmpty`. Make sure your template exports all of
them (the copy shipped here is a working fallback).

## Notes

- Requires Quickshell with the UPower, Hyprland, Pipewire and MPRIS services
  (current CachyOS repos build). Fonts: JetBrainsMono Nerd Font, Noto Sans CJK JP.
- Battery behavior is fully event-driven off `Quickshell.Services.UPower` —
  no polling. The charging shimmer runs 3 sweeps on plug-in and stops itself.
- VPN pill never toggles the VPN; click only refreshes. ProtonVPN daemon is
  `proton.VPN.service`; the connected state is detected by the presence of the
  `proton0` interface.
